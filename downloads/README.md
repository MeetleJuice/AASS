# Download status

The standalone connection-check patch ZIP has been withdrawn after a user reported
an antivirus warning. The exact detection is not known; no false-positive or
malware-free claim is made. Do not restore it from quarantine or disable protection.

The documented release process now requires dependency checks, Linux/Windows
tests, a Microsoft Defender scan result, checksums and an archive manifest.
Unsigned source is not a signed Windows app, and a checksum alone does not prove
safety. See docs/REMEDIATION-PLAN.md for the audit and release acceptance criteria.
