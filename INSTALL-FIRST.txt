AASS 1.3.2 - DESKTOP INSTALLATION
================================

1. Extract the complete ZIP to a new folder on your Desktop.
2. Double-click Install-AASS.bat. Keep the progress window open.
3. Setup checks GitHub, installs the permanent app, checks local tools and creates
   your custom AASS desktop icon. Select your existing private .env file if needed.
4. Use the desktop icon from then on. Click Update in the app for future releases.

Update verifies the full published release, preserves settings, checks the new
runtime and restarts. If it fails, the previous app/runtime are restored.
Source-only updates reuse installed dependencies. Projects remain separate.

Python 3.12 with Tcl/Tk, Docker Desktop and Ollama are required. Existing tools and
models are reused. Windows features/restarts and API account access/credits may
need the owner. Local setup makes no paid model requests. Test connections is
explicit and may incur API charges. Keep your chosen credential file in place.

Permanent installation: %LOCALAPPDATA%\Programs\AASS
Status/recovery: .aass inside the installed application.
Instructions: docs/WINDOWS-INSTALL.md and docs/INSTALL-UPDATE-PLAN.md
Keep Windows protection enabled. Published releases include scan/checksum evidence.

For automatic first-run cloud validation, explicitly opt in in your private file:
AASS_SETUP_ALLOW_BILLABLE_CHECK=1
AASS_JUDGE_SERVICE=gemini
Use your intended provider ID if different. Up to three API review calls may be
billed for a new configuration. Without consent, click Test connections once.
See docs/AUTOMATIC-SETUP.md for providers and custom model endpoints.
