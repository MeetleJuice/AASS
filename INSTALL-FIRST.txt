AASS 1.2.0 — WINDOWS GUIDED SETUP
================================

1. Extract the complete release ZIP. Open the extracted folder.
2. Double-click Install-AASS.bat. Keep Docker Desktop open.
3. In the setup window, choose your existing private .env / text file if it
   wasn't detected. A .env or .env.txt beside the installer is recognized.
4. Choose your provider and a model from the available-model dropdown.
5. Click Test connections (uses API), then open the Run a task tab.
6. Browse to your project, enter your task, and click Run task (uses API).

Later, double-click Start-AASS.bat. No PowerShell commands are needed.

Existing Python 3.12, Docker Desktop, Ollama and models are reused. Downloads
show progress; completed stages can be reused after cancellation or retry.
A cloud error stays in this window and never requires reinstalling packages.
Your key contents stay in your private file. Only its path and model selection
are saved. Local installation and model-list loading do not generate paid calls.

If Docker needs WSL/Virtual Machine Platform or a Windows restart, use the
Docker / Windows help button, complete that Windows step, then retry local setup.
Python needs its Tcl/Tk component for the window. Missing system prerequisites
and API account access/credits still need the machine/account owner.

Use the full release from https://github.com/MeetleJuice/AASS/releases/latest
It includes a checksum, Defender report and build provenance. Source is unsigned.
Keep Windows protection enabled. Do not use the withdrawn diagnostic patch.
