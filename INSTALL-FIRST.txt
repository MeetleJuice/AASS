AASS 1.1.0 — WINDOWS
===================

Use the full release ZIP from GitHub Releases, with the scan report and checksum.
Do not use the withdrawn diagnostic patch or restore anything from quarantine.

1. Extract all release files. Open the extracted folder.
2. Double-click Install-AASS.bat. Leave the progress window open.
3. After local setup, the menu opens. Choose your cloud provider if needed.
4. Choose Check model connections when ready to make real (potentially paid) API calls.
5. Later, double-click Start-AASS.bat and choose your project/task.

Your existing Python 3.12, Docker Desktop, Ollama and models are reused. Missing
system prerequisites are reported; automatic winget installation requires the
explicit --install-prerequisites option. Windows feature changes/restarts and
API account access/credits need the machine/account owner.

Desktop .env and bounded credential folders are recognized. Key values are not
printed or written into the release. Select the provider whose API key you intend
to use; keys can stay in your existing private file. An API quota/auth error means
fixing that provider/account, not reinstalling Python/Docker or the application.

The installer verifies release file hashes and local sandbox/browser checks.
A checksum is not antivirus clearance. Consult the separate Defender report for
the exact archive. Source is unsigned; no Windows signing certificate is bundled.
Do not disable antivirus or add exclusions for AASS.

Instructions: docs/WINDOWS-INSTALL.md
Review: docs/SECURITY-REVIEW.md
Local logs/status: .aass (inside the application folder; do not share credentials).
